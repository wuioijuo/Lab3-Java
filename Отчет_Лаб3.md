1. Создать интерфейс `Meowable`.
2. Добавить в интерфейс метод `meow()`.
3. Реализовать интерфейс в классе `Cat`.
4. Создать дополнительный класс `Dog`, также реализующий интерфейс.
5. Создать метод, принимающий массив объектов типа `Meowable`.
6. В цикле вызвать метод `meow()` у каждого объекта.
7. Проверить работу на нескольких котах и другом объекте.
